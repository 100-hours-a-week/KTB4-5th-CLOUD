# v3 비용 산정 및 구현 예산

> 기준일: 2026-10-26 / 구현 참고 자료
>
> 운영 설계: [v3 인프라 설계](../design/v3%20인프라%20설계.md)

비용 상한은 현재 인프라 설계의 제약조건으로 사용하지 않습니다. Replica·Node·DB·VPN·GCP 구성은 필요한 처리 용량과 가용성을 기준으로 정하고, 실제 구현 예산은 별도로 검토합니다.

## 1. 산정 기준

- AWS 서울 `ap-northeast-2`, GCP 서울 `asia-northeast3`를 사용합니다.
- 각 구성요소를 월 730시간 상시 운영하는 기준으로 계산합니다.
- 예산 환산 기준은 1 USD = 1,500원, 부가세 10%입니다.
- 무료 체험·약정 할인은 반영하지 않으며, GKE 무료 관리 크레딧은 적용 여부를 별도로 표시합니다.
- VPN은 EC2·GCE에 직접 설치하므로 관리형 VPN의 터널·연결 시간 요금을 적용하지 않습니다.

## 2. 확인한 AWS 단가

2026-10-26 AWS 공식 요금표와 Price List API에서 확인했습니다. EC2는 서울·Linux·공유 tenancy 기준이며 디스크·IP·전송 비용은 별도입니다.

| 항목 | 시간당 USD | 월 USD | 원화·부가세 반영 | 비고 |
|---|---:|---:|---:|---|
| EKS 표준 지원 관리 요금 | $0.10 | $73 | 120,450원 | 클러스터 1개 기준 |
| `m7i.large` | $0.1239 | $90.447 | 약 149,238원 | 앱 Node 기준 사양, SKU `UJJMFBN4RBJ2G2DD` |
| `t3.small` | $0.026 | $18.98 | 31,317원 | 견적 비교용, SKU `PZHVQ3KFPA3RHA5V` |
| `t3.micro` | $0.013 | $9.49 | 약 15,659원 | 견적 비교용, SKU `NYVHMS44MY8N2F3M` |

`t3.small`·`t3.micro`의 조회는 VPN·Orchestrator 사양의 채택을 의미하지 않습니다. T3의 추가 CPU 크레딧 비용은 위 기본 실행 요금과 구분합니다.

## 3. 앱 Node 상시 운영 비교

| 앱 Node | 월 누적 Node 시간 | 월 EC2 실행 비용 |
|---|---:|---:|
| `m7i.large` 1대 | 730시간 | 약 149,238원 |
| `m7i.large` 2대 | 1,460시간 | 약 298,475원 |
| `m7i.large` 4대 | 2,920시간 | 약 596,950원 |

Pod 개수 자체의 요금이 아니라 실제 Node의 사양·대수·실행 시간에 따른 비용입니다. 최대 4대를 모두 상시 유지하는 비교에서도 실행 시간을 줄여 예산에 맞추지 않습니다.

## 4. 전체 비용 산정의 남은 항목

EKS 1개와 시스템용·앱용 `m7i.large` 각 1대의 부분합은 월 약 418,925원입니다. 이는 전체 인프라 견적이 아니며 시스템용 고정 대수를 1대로 확정한 것도 아닙니다.

전체 상시 운영 견적에는 시스템용 Node의 고정 대수, AWS MySQL Primary·Standby·Read Replica 2대와 Orchestrator, GKE 관리 요금·최소 Node, GCP MySQL Replica, VPN VM 2대, 각 VM의 디스크와 Redis PVC, ALB·NAT·공인 IP, 백업·로그·데이터 전송 등을 합산합니다. 사양·수량·트래픽이 미정인 항목은 확정 요금처럼 기록하지 않습니다.

## 5. 구현 예산 참고

이전에 제시한 구현 예산은 전체 인프라 월 최대 120만 원, 그 안에 포함되는 AWS 앱용 EC2 월 20만 원 이하였습니다. 시스템용 Node·DB·VPN·EKS·GCP 등은 앱 EC2 예산과 구분합니다. 현재는 이 금액으로 운영 설계의 용량이나 가동 범위를 축소하지 않고, 실제 구축 전에 예산과 구현 범위를 다시 검토합니다.
