# 개발 부하 검증 계정

- 대상: `https://dev.dameokja.com`
- 생성기: `provision_accounts.py`
- 계정 파일: `private/accounts.json` (Git 제외)
- 아이디와 닉네임: `vu` + 실행별 임의 접두사 + 001~200
- 비밀번호: 계정별 서로 다른 영숫자 24자리. 아이디와 비밀번호에 `test`를 포함하지 않는다.
- 각 계정의 `refrigeratorIds`에 로그인 응답의 개인 냉장고 ID를 보관한다.
- `status: verified`는 가입 후 새 쿠키 저장소로 로그인하여 accessToken과 냉장고 ID를 확인했다는 뜻이다.
- 이 JSON에는 평문 비밀번호가 포함되므로 공유 문서나 Git에 올리지 않는다.
- 생성은 순차 처리하며 각 계정 처리 후 0.5초 대기한다. 실패하면 중단하며 파일을 유지한다. 재실행은 검증 완료 계정을 건너뛴다. `attempting` 상태는 중복 가입 대신 로그인으로 복구를 시도한다.
- 이 작업은 계정 준비와 로그인 검증만 수행한다. 200명 동시 부하 테스트는 별도로 실행해야 한다.
- 기존 `ingredients.js`는 단일 계정 세션을 공유한다. 이 파일에 계정 JSON을 연결하는 것만으로 독립 사용자 200명 테스트가 되지 않으며, 각 VU가 서로 다른 계정으로 로그인하도록 스크립트 변경이 필요하다.

WSL에서 계정 파일 위치(저장소 루트 기준):

```text

```
